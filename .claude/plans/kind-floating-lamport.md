# 调整 AI 优化提示词：中英文/数字间距规则

## Context

AI 输出中中文字符与英文单词/数字之间缺少空格（如 "使用React框架" 而非 "使用 React 框架"），影响阅读。需在 prompt 中增加间距规则，同时保留带单位的数字不被拆开。

## 修改方案

### 修改文件：`api/ai/prompts.ts`

在 SOCIAL_SYSTEM_PROMPT 和 CAMPUS_SYSTEM_PROMPT 的步骤 2.6 之后新增：

**步骤 2.7: 中英文间距规则**

- 中文与英文单词之间加空格：`使用 React 框架`
- 中文与独立数字之间加空格：`提升了 30`
- 数字紧跟单位时不加空格：`200ms`、`56%`、`3 台`、`5 个`
- 技术名称含版本号时跟随用户输入格式：用户写 `Vue3` 则输出 `Vue3`，用户写 `Vue 3` 则输出 `Vue 3`
- 行内代码（\`...\`）、加粗（\`**...\*\`）等 Markdown 标记内容视为整体，与中文之间加空格

同时在两个 prompt 的质量检查清单中新增一条检查项。

## 验证

触发 AI 优化，确认输出中 "使用 React 框架" 而非 "使用React框架"，"200ms" 不被拆为 "200 ms"
